## 🛠️ Especificações Técnicas e Padrões RFC

Padrões universais implementados em nossas APIs e sistemas:

*   **RFC 7807 (Problem Details for HTTP APIs):** [IETF Datatracker — RFC 7807](https://datatracker.ietf.org/doc/html/rfc7807) — Padrão obrigatório para todas as respostas de erro nos backends Express 5.
*   **OAuth 2.0 Authorization Framework (RFC 6749):** [IETF Datatracker — RFC 6749](https://datatracker.ietf.org/doc/html/rfc6749) — Implementado via Ory Hydra no Identity.
*   **Proof Key for Code Exchange by OAuth Public Clients (RFC 7636 - PKCE):** [IETF Datatracker — RFC 7636](https://datatracker.ietf.org/doc/html/rfc7636) — Obrigatório para SPAs React.
*   **Conventional Commits 1.0.0:** [conventionalcommits.org](https://www.conventionalcommits.org/en/v1.0.0/) — Padrão obrigatório de mensagens de commit Git.
