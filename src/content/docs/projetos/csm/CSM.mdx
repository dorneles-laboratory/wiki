# Murais Digitais (CMS / CSM)

<Badge text="Referência Arquitetural" variant="success" size="large" />

O **Murais Digitais (CSM)** é o sistema de sinalização digital (*Digital Signage*) do ecossistema Dorneles Laboratory, projetado para gerenciamento remoto, agendamento e exibição contínua de conteúdos informativos, avisos acadêmicos, previsão meteorológica e comunicados oficiais em TVs, totens e monitores instalados em campi universitários.

> [!IMPORTANT]
> **Fonte de Verdade Arquitetural:** O CSM é o projeto com maior maturidade do ecossistema. Qualquer padrão arquitetural adotado no CSM (estrutura de Docker Compose, padrões de Makefile, convenções de código em CSS Modules, tratamento de erros RFC 7807, observabilidade OTel) é o modelo oficial a ser replicado em todos os outros projetos da família.

## 🏗️ Topologia Técnica

O projeto é estruturado como um monorepo por acoplamento via submódulos Git:

```
csm/
├── apps/
│   ├── backend/       # Express 5, Prisma 7, PostgreSQL, MinIO S3, Pino, OpenTelemetry
│   ├── frontend/      # SPA React 19, Vite 7, CSS Modules, React Query, Zustand
│   └── wiki/          # Submódulo da Wiki com documentação local
├── packages/
│   └── shared/        # Contratos Zod 4.x e tipos inferidos compartilhados
├── docs/              # Decisões arquiteturais locais e especificações
└── Makefile           # Automação de ciclo de vida (dev, test, lint, build, db)
```

## 📐 Padrões de Código Rigorosos

- **CSS Modules:** É terminantemente proibido o uso de Tailwind CSS ou classes utilitárias inline. Cada componente possui seu arquivo correspondente `Component.module.css`.
- **Validação Segura:** Toda rota Express valida `req.body`, `req.query` e `req.params` com `safeParse` de schemas definidos no pacote `packages/shared`.
- **RFC 7807:** Respostas com códigos de erro utilizam a estrutura padronizada de Problem Details.
- **Rastreamento OTel:** Instrumentação nativa propagando `x-request-id` e traces em todas as operações de banco e storage.
