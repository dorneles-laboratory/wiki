# Motor de Monitoramento Sintético

O FederalStatus possui uma arquitetura híbrida de aferição em tempo real da saúde dos serviços cadastrados pelas universidades federais, combinando agendadores internos com monitoramento distribuído na borda via Cloudflare Workers.

## 1. Cloudflare Ping Worker (`packages/ping-worker`)

Para garantir confiabilidade, contornar bloqueios regionais e não sobrecarregar o container do backend, as probes ativas são despachadas para um Edge Worker Serverless:

- **Cota:** Plano Free do Cloudflare Workers com suporte a 100.000 invocações/dia.
- **Concorrência:** Despacha até 50 subrequests paralelas por lote.
- **Tratamento de WAFs e Bloqueios:**
  - Headers HTTP completos emulando Chrome de última geração para evitar falsos positivos de proteção anti-bot.
  - Reconhece códigos 401, 403, 405 ou 468 como sinal de servidor online protegido (WAF/Turnstile ativo).
  - Reconhece erros 525 e 526 como servidores ativos respondendo com alertas de TLS na porta 443.
- **Autorização:** Apenas requisições autenticadas com o segredo compartilhado (`PING_WORKER_SECRET` / `CLOUDFLARE_WORKER_SECRET`) são processadas.

## 2. Funcionamento do Ciclo no Backend

1. **Agendamento Recorrente:** O scheduler em lote (`batch-scheduler.service.ts`) agrupa os alvos e despacha lotes de teste.
2. **Classificação de Status:**
   - **`ONLINE`:** Status HTTP `2xx` / `3xx` ou resposta com latência adequada.
   - **`UNSTABLE`:** Degradação severa de latência ou alertas de certificado iminente.
   - **`OFFLINE`:** Timeouts esgotados ou ausência total de resposta TCP/DNS.
3. **Persistência de Telemetria e Rollup:**
   - Registros instantâneos gravados em `ServicePingLog`.
   - Agregação consolidada em `UniversityServiceMetric` via `retention-rollup.service.ts` com políticas de expiração de dados brutos.
