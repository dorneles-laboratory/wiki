## Detalhes da Submissão

### **Título:**

> **SRM Simulator: Ambiente Computacional Desktop Para Simulação E Análise De Balística Interna De Motores A Propelente Sólido**

### **Resumo Submetido (166 palavras):**

> O Solid Rocket Motor Simulator (SRM) é uma aplicação desktop de código aberto desenvolvida para a simulação e análise de balística interna de motores foguete a propelente sólido. Projetado para substituir planilhas de cálculo legadas por um ambiente de engenharia moderno, rastreável e de alta performance, o SRM unifica a modelagem geométrica e a análise termo-balística do motor. O sistema conta com um editor de geometria parametrizado para carcaça, bocal e grãos propelentes (como a geometria BATES) com feedback visual em tempo real, além de gerar curvas de pressão, empuxo e impulso total. Sua arquitetura desacoplada emprega uma interface fluida em Tauri e React integrada a uma API REST embutida em Java 21 com Spring Boot, aliada a um banco de dados local com versionamento de esquema via Flyway. Essa abordagem garante execução totalmente offline-first, alta capacidade de processamento analítico e segurança dos dados. O SRM fornece à comunidade aeroespacial uma ferramenta padronizada, modular e acessível para a otimização e o dimensionamento seguro de propulsores sólidos.

**Palavras-chave:** Propulsão Sólida · Balística Interna · Simulação Computacional · Motores Foguete · Software Livre
